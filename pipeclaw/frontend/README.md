# Frontend

[中文](#中文) | [English](#english)

## 中文

这个前端是 PipeClaw 的公开体验入口，基于 React + Vite。它默认通过 Vite 代理把 `/api` 和 `/assets` 请求转发到 `http://localhost:8003`，因此本地开发时先启动后端，再启动前端即可。

启动方式：

```bash
npm install
npm run dev
```

## English

This frontend is the public interaction entrypoint for PipeClaw, built with React + Vite. It proxies `/api` and `/assets` to `http://localhost:8003` by default, so local development only requires starting the backend first and then the frontend.

Run it with:

```bash
npm install
npm run dev
```
